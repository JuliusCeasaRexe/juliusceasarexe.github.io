Política de Privacidade – Attila Backup

Última atualização: 30 de outubro de 2026

O que é

Attila Backup é um app de uso pessoal. Ele roda apenas no computador do próprio dono e é usado somente por ele.

Dados do Google acessados

O app usa a permissão do Google Drive para criar arquivos de backup em uma pasta do Drive do próprio usuário e para conferir se o envio foi concluído corretamente (nome, tamanho e checksum dos arquivos enviados).

Como os dados são usados

  • Os backups são criptografados no computador do usuário antes do envio.
  • Os dados ficam apenas no computador do usuário e no Google Drive dele.
  • Nenhum dado é enviado a terceiros, vendido, compartilhado ou usado para publicidade.
  • Nenhum dado é usado para treinar modelos de inteligência artificial.

Armazenamento e exclusão

O token de acesso fica guardado apenas no computador do usuário, com acesso restrito. O usuário pode revogar o acesso a qualquer momento em myaccount.google.com/permissions e pode apagar os backups diretamente no Google Drive.

Uso Limitado

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Contato

Pelo e-mail de suporte exibido na tela de autorização do Google.
